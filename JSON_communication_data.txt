		"roomPIN": "9999",

	}



*) the client publish the following message to the NodeJS server after the connection
	
	{
		"action": "client-info",
		"data": 
		{
			"appVersion": "1.0.0",
			"resolution":
			{
				"width": 1024,
				"height": 768
			}
		}
	}



*) if the NodeJS server check that the client is an old version it send the following message
	
	{
		"action": "app-need-update"
	}

*) when the controller send a goto scene action each clients receive this message:

	{		
		"sceneIndex": 0,
		"subSceneIndex": 0
	}


*) when the client start the presentation files download it send a message to the server:

	{
		"action": "download-start"
	}


*) when the client ends the presentation files download it send a message to the server:

	{
		"action": "download-ended"
	}


*) when the client show a scene/subscene it sends the following message to the server:

	{
		"action": "scene-changed",
                "data": 
                {
			"sceneIndex": 0, 
			"subSceneIndex": 0
		}
	}


*) when the client show a scene and has some error in its content it sends the following message to the server:

	{
		"action": "scene-content-error",
                "data": 
                {
			"sceneIndex": 0, 
			"contentIndex": 0
		}
	}
